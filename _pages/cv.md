## Experience


- **Security Researcher**, HarmonyOS System Security Team, Huawei, China (2024&ndash;present)<br>  Focus: HarmonyOS Security, Fuzzing, LLMs for Security, Static Analysis

  - Lead the kernel fuzzing technical roadmap for HarmonyOS, targeting memory-safety vulnerabilities in the kernel and system components.

  - Lead the Rust technical roadmap for HarmonyOS, eliminating memory-safety bug classes in new system components.

  - Apply LLMs to security analysis (AI for Security).


- **Research Intern**, Mentor: [Weidong Cui](https://www.microsoft.com/en-us/research/people/wdcui/), Systems Security and Privacy Research Group, Microsoft Research, USA (2023&ndash;2023)<br>  Focus: LLMs for Security / Program Analysis

  - Proposed E&V, an early approach that prompts LLMs to perform static analysis by executing pseudo-code and verifying the results, reducing hallucination without extra tooling.

  - Applied E&V to Linux kernel crash triage (locating the function to patch), achieving over 80% accuracy on 170 crashes across seven bug categories.


- **Research Intern**, Mentor: Kris Alder, Android Security Team, Google, USA (2022&ndash;2022)<br>  Focus: Linux/Android Kernel Security, Fuzzing, Static Analysis

  - Used static analysis to enhance Android kernel fuzzing (internal tooling).


- **Graduate Student Researcher**, Advisor: [Zhiyun Qian](https://www.cs.ucr.edu/~zhiyunq/index.html), Center for Research and Education in Cyber Security and Privacy (CRESP), University of California, Riverside, USA (2018&ndash;2024)

  - Built the under-constrained symbolic execution and much of the static-analysis tooling behind the group's kernel security projects listed below.

  - Kernel fuzzing: identified the root cause behind the “dependency challenge” (ICSE 22, Google Research Paper Reward); automated syscall specification generation via static analysis (SyzDescribe, S&P 23) and under-constrained symbolic execution (SyzSpec, CCS 25, Distinguished Paper Award); contributed ideas to dependency inference for driver fuzzing (SyzGen++, S&P 24).

  - Bug triage & exploitability: co-designed and built the symbolic execution for accurate bisection of fuzzer-exposed vulnerabilities (SymBisect, USENIX Security 24); built the static analysis for exploitability assessment across the Linux ecosystem (SyzBridge, NDSS 24).

  - Precise static analysis: built the under-constrained symbolic execution for Linux kernel use-before-initialization detection, eliminating about 87% of false positives (UBITect, FSE 20) and enabling incremental detection (NDSS 22).

  - LLM-assisted program analysis: contributed the ideas and static analysis for LLM-integrated static bug detection (FSE 23, OOPSLA 24).


- **Research Assistant**, Advisor: Ting Liu, Ministry of Education Key Lab For Intelligent Networks and Network Security, Xi'an Jiaotong University, China (2013&ndash;2018)<br>  Focus: Concurrency Security, Symbolic Execution
